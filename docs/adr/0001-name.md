# ADR 0001: Name — Janus

## Status

Accepted.

## Context

The project needs a name that expresses both halves of the product:

- memory: what you believed, what you knew, and how it turned out;
- foresight: probabilistic forecasts, scenarios, and regime changes.

Earlier candidates were either too abstract (Hindcast, Vintage, AsOf), too cute
(OpenFinch, Jay, Magpie), or covered only one half (Touchstone = verification,
Hindsight = review). The name should be concrete, memorable, and easy to say.

## Decision

Use **Janus**.

Janus is the Roman god of gates, transitions, beginnings, and endings. He is
depicted with two faces: one looking back, one looking forward. That is the
product in one image.

Tagline: **Janus remembers backward, reasons forward.**

## Consequences

- The two faces map directly to the Memory and Foresight layers.
- The "gate" metaphor fits market transitions and regime changes.
- The name is a real word with a concrete image, not a made-up compound.
- Existing collisions (Janus Henderson, Janus Gateway, JanusGraph) are in
  adjacent spaces; the repository will use a descriptive subtitle and topic tags
  to disambiguate.
